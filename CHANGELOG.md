# Changelog

What changed in pkm. The next version's changes are collected here; each released version's notes, including manual steps for existing vaults, are on its GitHub release, linked below.

Version numbers: **major** when a command, option, output format, note name, link syntax, frontmatter field or folder is renamed or removed, since agentic-pkms skills, editors and existing notes depend on them; **minor** for new commands, options and templates; **patch** for fixes. Before 1.0, a minor version may also need manual changes; its notes list them under "Manual steps". Each release is a git tag (`v0.1.0`), and `pkm version` shows which one is installed.

## 0.8.0 (unreleased)

- Where a `###` block ends: at the next heading, as before, or now also at a blank line after its lines that is followed by an entry (`- HH:MM …`). The entries after a block are no longer counted as about what its heading links, in `since --about`, `backlinks` and `--under`; those list fewer lines on pages that go on after a block.
- `pkm add`, and `pkm moved` on today's Log, write a blank line before an entry that follows a block, so the block ends there.
- Docs: the method says how to keep what is done every day, such as pills: a checklist in a list note, not a routine with `(every 1d)`.
- **Manual steps**: none. On a page written before, an entry glued to the end of a block stays in it; add a blank line before it to take it out.
